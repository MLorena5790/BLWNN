# BLWNN – Bayesian Learning for Wavelet Neural Networks

## Overview

This repository contains the computational implementation in R developed as part of the doctoral thesis entitled *Wavelets e aprendizagem bayesiana de redes neurais*, authored by Márcia Lorena Alves dos Santos.

The proposed methodology integrates wavelet activation functions into a Bayesian neural network framework, incorporating uncertainty into the estimation of network parameters, including wavelet translation and dilation parameters.

## Original Implementation

The BLWNN implementation is partially based on the original BLNN (Bayesian Learning for Neural Networks) package.

Original repository: https://github.com/BLNNdevs/BLNN

The original implementation was extended and adapted to incorporate wavelet activation functions and their associated parameters within the Bayesian learning framework.
